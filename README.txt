COLLEGE CANTEEN ORDERING SYSTEM
================================


HOW TO RUN:
1. Start XAMPP - ensure Apache and MySQL are running
2. Open phpMyAdmin (http://localhost/phpmyadmin)
3. Run the SQL setup script to create canteen_db database
4. Open project in NetBeans
5. Add mysql-connector-j.jar to Libraries
6. Set Main Class to: canteen.Main
7. Press F6 to run
